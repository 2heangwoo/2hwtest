Netlify 업로드 방법

이 폴더 안의 파일 3개를 함께 업로드하세요.

- index.html
- 1234.glb
- 1234.usdz

기능
PC/Android 웹: 1234.glb를 이용해 3D 모델 회전/확대
iPhone/iPad AR: 1234.usdz를 이용해 AR Quick Look
Android AR: GLB 기반 Scene Viewer/WebXR

주의
로컬에서 index.html을 더블클릭(file://)하지 말고,
Netlify에 올린 https 주소에서 확인하세요.

현재 웹 미리보기 GLB는 앞서 업로드한 FBX에서 만든 GLB를 사용합니다.
iPhone AR는 새로 올려주신 1234.usdz를 사용합니다.
